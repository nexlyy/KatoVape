# KatoVape

Магазин украинских вейпов в Польше: сайт, мини-приложение Telegram, панель управления и бот.
Раньше наличие вели постом с галочками в закрытом канале, теперь витрина сама читает базу и
показывает остатки, цены, вкусы и характеристики по каждому городу.

## Что внутри

Витрина (`demos/vapor/`) собрана на одном ядре `shared/core.js`: сайт и мини-приложение
Telegram отличаются только вёрсткой. Каталог, заказы, брони и отзывы живут в Supabase.

Панель управления (`demos/admin/`) закрыта входом и ролями. Владелец и разработчик видят
дашборд с выручкой и графиками, менеджер работает только со своим городом: заказы, брони,
ассортимент, клиенты, промокоды и рассылка.

Бот (`server/`) крутится на отдельном сервере и ходит только в Supabase и в Telegram. Он
проводит онбординг, шлёт менеджеру города новый заказ, напоминает о бронях и рассылает
сообщения.

Точка входа: `index.html`.

## Как это работает

Города разделены сверху донизу: у каждого свой каталог, свои остатки, свой канал, свой
менеджер и свои заказы. Менеджер Гливице не видит заказы Варшавы, и это закреплено политиками
базы, а не только интерфейсом.

Цену заказа считает сервер по своему каталогу. Браузер присылает только состав корзины,
поэтому подменить сумму или название товара из консоли не получится.

Языки: русский, украинский, польский. Переводятся и названия вкусов.

Оплата подключена через Stripe, но карта сейчас выключена флагом в `shared/config.js`:
кнопка честно говорит об этом и ведёт к менеджеру города.

Ещё на витрине: выбор города, корзина с оптовыми ступенями, бронь с датой и временем,
избранное, отзывы на купленный вкус, выбор пачкомата InPost, светлая и тёмная тема,
возрастной гейт.

## Запуск

```bash
node tools/serve.mjs
```

Дальше открыть `http://localhost:8788`. Мини-приложение удобно смотреть в мобильном виде
браузера, внутри Telegram нижняя кнопка становится нативной.

Тесты в базу не ходят, но проверяют расчёты, словари и правила доступа:

```bash
npm test
```

После правки `shared/*.js` надо обновить версии подключений, иначе браузеры отдадут старый
файл из кеша:

```bash
npm run stamp
```

## Данные

- `data/products.json`: Катовице и список городов.
- `data/gliwice.json`, `data/warszawa.json`: остальные города.
- `data/photos/`: фото товаров (`<id>.jpg`) и логотипы городов (`cat-<city>.png`).
- `data/inpost/`: выгрузка пачкоматов на случай, если справочник InPost недоступен.

Файлы задают структуру каталога, живые цены и остатки приходят из базы поверх них.
